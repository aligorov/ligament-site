The Future of Ligament On-Premise

We continuously expand the unified On-Premise security perimeter. Beyond currently shipped components (Core, Windows Logon, RADIUS 802.1X, SSO OIDC/SAML, and Branch Relay), our team is actively architecting new products for remote administration and physical access control.

Ligament Link

Remote desktop under your control

We are developing an on-premise alternative to TeamViewer and AnyDesk within the Ligament 2FA ecosystem, for IT support, administration and access to an office PC from home without third-party clouds.

On-Premise Console Sharing 2FA / Passkey / Push

What we are building

One environment for device access, second-factor authentication, permission revocation and audit.

The features below describe the development roadmap. Release timing, supported platforms, release scope and licensing will be announced separately.

Discuss early access

Planned capabilities

Shared desktop

Console sharing lets the operator and employee see the same desktop and work together without opening a separate RDP session.

Unattended access

Planned access to locked PCs, login-screen interaction and Ctrl+Alt+Del. Access follows assigned permissions and the 2FA policy.

Your own infrastructure

Planned deployment of servers, relays and keys within the organization’s infrastructure. Screen and file traffic stays within that deployment.

HTTPS / WSS :443

Secure outbound connections to your infrastructure, without inbound port forwarding on workstations. Connectivity depends on network policies and proxy configuration.

Central access revocation

Planned centralized access control and termination of active sessions from Ligament 2FA when a user is blocked or a permission is revoked.

Device inventory and audit

Planned Windows/Linux device inventory with status and connection logs: user, source device, target host, time and access mode. Event integration with SIEM.

For security teams: managed access instead of untracked remote connections.

For IT teams: help employees in their current console and service devices without the user present.

For employees: access the familiar office desktop with 2FA, without a mandatory separate office VPN.

Link / Bastion: Bastion provides RDP/SSH forwarding through Core or Relay. Ligament Link is being developed for shared-console access and remote assistance as a separate product direction.

Ligament PACS

Physical access control & turnstiles under 2FA perimeter

We are developing native integration between Ligament 2FA and Physical Access Control Systems (PACS): turnstiles, doors, and server room access validated via mobile Passkey/Push. Eliminates badge borrowing (Anti-Passback) and automatically locks the Windows desktop when leaving the premises.

On-Premise Anti-Passback + MFA Auto-Lock Windows Bolid / Sigur / RusGuard

Zero-Trust Physical Convergence

Bridging physical access control and digital identity in a single security perimeter.

The features below outline the architectural roadmap for Ligament PACS. Release timing, controller support lists, and licensing will be announced separately.

Discuss PACS early access

Planned PACS Capabilities

Turnstile 2FA Validation

Tapping an RFID/HID badge sends an instant Push or Passkey prompt to the employee's phone. Turnstile opens only upon personal biometric confirmation.

Auto-Lock on Office Exit

Turnstile exit events automatically trigger an immediate Lock Screen for active Windows Logon and RDP sessions on the employee's workstation.

Anti-Passback Enforcement

Prevents badge lending: access to server rooms or high-security zones requires FaceID/TouchID confirmation on the registered mobile device.

PACS Controllers Interoperability

Compatibility with Bolid Orion Pro, Sigur, RusGuard, HikCentral, Perco, and Wiegand/OSDP hardware controllers via native APIs and Webhooks.

Ghost Logon Detection

Instant SIEM alert when an Active Directory, RDP, or VPN session originates for an employee who has not badged into the physical facility.

Converged Audit & SIEM

Unified timeline correlating turnstile badges with Windows logins and 802.1X Wi-Fi connections, exported directly to corporate SIEM via Syslog/CEF.

For Physical Security: eliminate badge borrowing and instantly revoke both physical turnstile and domain access with one click.

For SOC & InfoSec: detect impossible logins by correlating physical location data with corporate credentials.

For IT Administration: automatic lock for abandoned workstations without requiring employee action or short idle timers.

PACS / RADIUS: RADIUS secures Wi-Fi and VPN network connections, while Ligament PACS secures doors, gates, and synchronizes real-world presence with workstation session locks.
