# Ligament Website

Репозиторий сайта-визитки / лендинга Ligament.

## Команды для публикации в приватный репозиторий GitHub

1. Создать приватный репозиторий на GitHub и привязать remote:
   ```bash
   gh repo create aligorov/ligament-site --private --source=. --remote=origin --push
   ```

   Либо вручную:
   ```bash
   git remote add origin https://github.com/aligorov/ligament-site.git
   git push -u origin main
   ```
