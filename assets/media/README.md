# Медиа-ассеты сайта Ligament

Все скриншоты и видео управляются через `manifest.json` в этой папке.
Если файла нет — сайт показывает аккуратный плейсхолдер.

## Скриншоты
- **Формат**: PNG, 1600×1000 px (16:10), ≤ 350 КБ (pngquant/oxipng)
- **Тема**: единый стенд, тёмная тема `#111827`
- **Маскировать**: реальные ФИО/IP/домены, Activation Code `LG-XXXX-…`, recovery codes
- **Имя**: `screen-<id>.png` по manifest.json

## Видео
- **Формат**: `.webm` (VP9) + `.mp4` (H.264 High), 1920×1080, ≤ 90 с, ≤ 60 МБ
- **Постер**: `<id>-poster.jpg`, 1920×1080, JPEG 85%, ≤ 120 КБ
- **Без звука**: `muted`, `playsinline`, `preload="none"`

## СКУД-медиа
Скриншоты и видео раннего модуля СКУД **не публикуются** до подтверждения владельцем.
